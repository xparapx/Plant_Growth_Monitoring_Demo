01

프로젝트 요약

"수분의 변동성이 식물 생장을 바꾸는가"를 센싱 → 폐루프 급수 → 카메라 계측 → 통계 검정으로 직접 구성하는 프로젝트입니다.

환경 노드(UNO R4 WiFi + BME688 + SCD41 + BH1750)가 온습도·기압·VPD·CO₂·조도를, 급수 노드(M5Stack Core S3 + Watering Unit)가 화분별 토양수분을 측정해 NTP 정각정렬로 5분 평균 1건을 MQTT로 발행합니다. 각 급수 노드는 브로커가 죽어도 급수를 계속하는 독립 상태기계(dose·soak·verify·일일상한·fail-safe)입니다. 허브(처음엔 PC, 이후 Raspberry Pi 5)의 run_collector.py가 메시지를 구독해 SQLite에 쌓고, Pi 카메라가 하루 2회(06:00·15:00) 위에서 찍은 사진을 ExG + Otsu로 분할해 투영 캐노피 면적(cm²)으로 환산합니다. Streamlit 대시보드가 환경·급수·생장을 한 화면에서 보여주고, 처리군을 늘리면 칸이 자동으로 추가됩니다.

03

핵심 가설 — 왜 변동성인가

평균은 같게, 흔들림만 다르게.

두 처리군은 평균 토양수분을 똑같이 맞추고 변동폭만 다르게 둡니다 — 꾸준군(좁은 밴드)과 널뜀군(넓은 밴드). 총 급수량은 통제하지 않고 결과로 따라 나옵니다. 수분–생장 곡선이 휘어 있으면(옌센 부등식), 평균이 같아도 변동성이 생장의 평균을 끌어올리거나 끌어내립니다.

E[f(수분)] ≠ f(E[수분]) ← 곡률 f″의 부호가 방향을 정한다

측정값은 원면적이 아니라 RGR(상대생장률, (ln A₂ − ln A₁)/Δt) — 큰 개체가 절대량으로 더 자라므로 원면적 비교는 부당합니다. 결과 해석의 정직함을 위해 파종 전 사전등록으로 가설·분석·효과크기를 미리 못 박습니다.
